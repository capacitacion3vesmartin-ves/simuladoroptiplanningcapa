Acerca de Optiplanning

Optiplanning Web Replica v4.2

Optimizador de corte industrial para carpintería

Optiplanning es un software interactivo de optimización de corte guillotina 2D para tableros de melamina, madera, MDF y triplay.

  • Algoritmo Heurístico de Corte Guillotina 2D.
  • Soporte de Veta / Sentido de Fibra (0, 1, 2).
  • Cálculo exacto de kerf de sierra y refilo exterior.
  • Identificación gráfica de Retazos Reutilizables.
